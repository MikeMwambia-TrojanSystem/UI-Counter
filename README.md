# usdc_counter

This is the Digital assets counter.
This is the UI of coutner.

It is made up of three amjor parts :- 

Dashbaord Onboarding - This involves the creation of new dashboards to sell your crypto.

Dashboard Broadcasting - This module ensures the dashboards that are created are displayed and updated frequently,it is also responsible for expiring the dashbaords which have gone past time.

Order Servicing - This module ensures that digital assets that are bought are delivered to their respective wallets and ensures payment has been done.
